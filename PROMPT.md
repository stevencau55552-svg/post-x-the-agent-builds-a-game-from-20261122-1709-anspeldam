# The ONE prompt

This is the single prompt the agent was given. One prompt, no follow-ups,
no edits — the game in `game.html` is everything it produced from this text
alone:

> Build a tiny browser game in one HTML file: ORBIT DODGE, a neon space
> dodger. I pilot a small ship with arrow keys, mouse or touch. Asteroids
> fall from the top — dodge them. Glowing stars fall too — collect them for
> points. 3 lives, faster as I score. Particles and screen shake on a hit,
> game-over screen with restart. Canvas 2D, dark starfield, magenta and
> cyan neon, WebAudio bleeps. No libraries, no network, everything inline.

The video (`video/game-video.mp4`) shows this prompt being typed, the agent
working, and the finished game running — the game in the video is this file,
`game.html`, playing for real.
